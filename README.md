## Struktura kapitol

Každá kapitola obsahuje:
- **Teorii** s Mermaid diagramy
- **Postupy krok za krokem**
- **Reálné příklady**
- **Tipy a časté chyby**
- **Praktická cvičení**
- **Shrnutí a kontrolní otázky**
- **Zdroje a odkazy**

## Požadavky

- Prohlížeč s podporou Mermaid (GitHub, VS Code s rozšířením)
- Základní znalost příkazové řádky (terminál)
- Pro praktická cvičení: nainstalovaný `dig`, `nmap`, `exiftool`, `whois`
