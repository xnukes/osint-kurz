# 15.2 Samostatné úkoly

> **Cíle kapitoly:**
>
> - Procvičit všechny techniky samostatně
> - Ověřit si znalosti
> - Připravit se na závěrečný projekt

---

## Úkoly podle oblastí

### 1. Vyhledávání (kapitola 3)

1. Najděte všechny PDF dokumenty na doméně ministerstva (např. mvcr.cz)
2. Najděte LinkedIn profily IT bezpečnostních specialistů v Praze
3. Pomocí Wayback Machine najděte verzi webu idnes.cz z 1.1.2010
4. Sestavte Google dork pro nalezení otevřených webkamer
5. Najděte nejstarší snapshot své oblíbené stránky na Wayback Machine

### 2. Domény a DNS (kapitola 4)

1. Proveďte WHOIS na 3 domény a porovnejte výsledky
2. Zjistěte SPF, DKIM a DMARC pro seznam.cz
3. Najděte všechny subdomény své školy pomocí crt.sh
4. Pomocí reverse IP zjistěte další domény na stejné IP jako cíl
5. Zjistěte ASN pro IP 1.1.1.1 a 8.8.8.8

### 3. IP a infrastruktura (kapitola 5)

1. Geolokujte IP svého ISP
2. Proveďte port scan na scanme.nmap.org
3. Získejte banner z HTTP serveru scanme.nmap.org
4. Zjistěte, jestli cílová doména používá Cloudflare
5. Zmapujte infrastrukturu jednoduché domény

### 4. Metadata (kapitola 6)

1. Extrahujte EXIF z fotografie z vlastního telefonu
2. Najděte autora a datum vytvoření PDF dokumentu
3. Extrahujte metadata z DOCX souboru
4. Odstraňte všechna metadata z fotografie
5. Porovnejte EXIF před a po odstranění

### 5. Sociální sítě (kapitola 7)

1. Pomocí Sherlocku vyhledejte uživatelské jméno napříč platformami
2. Analyzujte Instagram profil veřejné osoby
3. Najděte LinkedIn profily zaměstnanců vybrané firmy
4. Použijte Nitter pro anonymní prohlížení Twitteru
5. Vyhledejte Telegram kanál na libovolné téma

### 6. E-maily (kapitola 8)

1. Analyzujte hlavičky e-mailu, který jste poslali sami sobě
2. Zkontrolujte SPF/DKIM/DMARC pro doménu bez ochrany
3. Zkontrolujte svůj e-mail na haveibeenpwned.com
4. Použijte Epieos pro analýzu e-mailu
5. Najděte Gravatar obrázek pro známý e-mail

### 7. Telefonní čísla (kapitola 9)

1. Použijte Numverify pro analýzu telefonního čísla
2. Použijte PhoneInfoga na testovací číslo
3. Zkontrolujte, zda číslo používá WhatsApp
4. Identifikujte VoIP číslo
5. Zjistěte operátora z předvolby čísla

### 8. Geolokace (kapitola 10)

1. Určete místo fotografie bez GPS
2. Pomocí SunCalc analyzujte stín na fotografii
3. Porovnejte historické satelitní snímky v Google Earth
4. Proveďte Street View prohlídku 3 míst v ČR
5. Použijte Overpass Turbo pro nalezení restaurací v okruhu 500m

### 9. Dark Web (kapitola 11)

1. Ověřte funkčnost Tor Browseru na check.torproject.org
2. Navštivte DuckDuckGo onion verzi
3. Použijte Ahmia pro vyhledání tématu
4. Porovnejte fingerprint s a bez Tor Browseru
5. Zdokumentujte 3 legitimní onion služby

### 10. Úniky dat (kapitola 12)

1. Zkontrolujte 3 své e-maily na HIBP
2. Ověřte pravost náhodného úniku z internetu
3. Analyzujte JSON soubor s uniklými daty (pokud máte)
4. Navrhněte bezpečnostní doporučení pro firmu po úniku
5. Vytvořte plán reakce na únik dat

### 11. Metodika (kapitola 13)

1. Vytvořte časovou osu pro vývoj webové stránky
2. Vytvořte link analysis graf pro jednoduchý příklad
3. Ohodnoťte confidence level pro informaci z jednoho zdroje
4. Napište executive summary pro fiktivní případ
5. Vytvořte kompletní závěrečnou zprávu

### 12. Komplexní úlohy

1. **Profil osoby:** Najděte co nejvíce informací o veřejně známé osobě (politik, sportovec)
2. **Analýza firmy:** Proveďte due diligence na malou firmu
3. **Analýza domény:** Kompletní profil domény
4. **Geolokace:** Určete místo neznámé fotografie
5. **Infrastruktura:** Zmapujte infrastrukturu webové služby
